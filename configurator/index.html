Choose the input source your computer uses (on a Mac, the one in the menu bar), including on its login screen. Typed text, saved secrets and the unlock password are typed through it, and shortcut letters follow it.
The password is write-only. It is encrypted with a key stored on your RFID tag, never on the Pico, and the device refuses to send it back, so it cannot be displayed here or read by anything else on the serial port. There is no "reveal", only "replace". Changing it requires the current one. Lose the tag and the password must be set again; that has no recovery path by design.

Advanced: read/write tag memory

Your tag has a small amount of storage you can read and write directly. This is a maintenance tool, it does not run the tag's assigned actions.
Block 5 holds the tag's encryption key. Writing to it permanently destroys the stored password and secrets on this tag; you'll be asked to confirm first.

What is MIFARE?
MIFARE is the family of RFID chips inside your tags, made by NXP. The name comes from MIkron FARE collection, since the first ones were built for public transport ticketing. Your tags are MIFARE Classic, the type that ships with nearly every RC522 kit.

It matters here because MIFARE Classic has writable memory, not just a serial number. A simpler tag would only give you a UID you can read, and storing an encryption key on it would be impossible.

How the memory is arranged
Storage is split into fixed slots of 16 bytes each, called blocks. Every fourth block is a "sector trailer" that holds the card's own access keys:

BlockHolds
0Manufacturer data, including the UID. Read only.
1, 2Free space, unused by this project.
3Sector trailer. Access keys, never written.
4The optional text label written onto the tag.
5Your AES encryption key. Overwriting it destroys the password and secrets.
6Free space.
7Sector trailer.
8+The pattern repeats: three free blocks, then a trailer.

Sector trailers are refused by the device. Writing one would change the card's own access keys and could make that part of the tag unusable for good.

What is "Key A"?
Separate from your encryption key. It is MIFARE's own access control: the card refuses to read or write a sector without it. Blank tags ship with the factory default FFFFFFFFFFFF, which is why the field is prefilled and you have never needed to enter one.
